# Resources

External places to practise, learn and listen. The list is short on purpose: pick a few and stick with them.

> **A note on links:** official sites and channels are linked directly. For individual YouTube
> videos I give the channel and the exact title to search for, because I could not confirm a
> stable URL for each video. If a link ever breaks, search for its title.

## Practice platforms (write code, get told right or wrong)

| Site | Best for |
|---|---|
| [LeetCode](https://leetcode.com/) | The standard for interview-style problems. Start with Easy. |
| [NeetCode](https://neetcode.io/) | Curated problem lists (see the [NeetCode 150](https://neetcode.io/practice)) with a short video explanation for each. |
| [Exercism](https://exercism.org/) | Free, mentored language tracks you solve locally with tests. Good for learning a language properly (Python, JavaScript, TypeScript, Swift and more). |
| [HackerRank](https://www.hackerrank.com/) | Many UK employers send HackerRank-style online tests, so get used to the format. |
| [Codewars](https://www.codewars.com/) | Short "kata" puzzles, good for daily warm-ups. |
| [CodeSignal](https://codesignal.com/) | Another platform employers use for online assessments. |
| [Advent of Code](https://adventofcode.com/) | December puzzle event; fun once you are fluent. |

## Learn Python

- [The official Python tutorial](https://docs.python.org/3/tutorial/)
- [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/): free Harvard course, lectures and problem sets
- [Python for Everybody](https://www.py4e.com/): gentle, free course and book
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/): free book, practical scripting
- [Real Python](https://realpython.com/): articles and tutorials (some paywalled)
- YouTube: [Corey Schafer](https://www.youtube.com/@coreyms) (clear Python fundamentals), [mCoding](https://www.youtube.com/@mCoding) (deeper Python), [ArjanCodes](https://www.youtube.com/@ArjanCodes) (design and clean code)

## Learn JavaScript and TypeScript

- [javascript.info](https://javascript.info/): the best free, thorough JavaScript tutorial
- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) and the MDN reference for every method
- [The TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) and the [TypeScript Playground](https://www.typescriptlang.org/play)
- [Total TypeScript](https://www.totaltypescript.com/): free tutorials and articles by Matt Pocock
- [You Don't Know JS Yet](https://github.com/getify/You-Dont-Know-JS): free book series on how the language really works
- [freeCodeCamp: JavaScript algorithms and data structures](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/): free, interactive in the browser
- [Exercism: JavaScript track](https://exercism.org/tracks/javascript) and [TypeScript track](https://exercism.org/tracks/typescript)
- [Node.js: running TypeScript natively](https://nodejs.org/api/typescript.html) and the [Node.js test runner](https://nodejs.org/api/test.html) (what this repo uses)
- Podcast: [Syntax](https://syntax.fm/) (web development, JavaScript and TypeScript)
- YouTube: [Fireship](https://www.youtube.com/@Fireship) (short overviews), [Matt Pocock](https://www.youtube.com/@mattpocockuk) (TypeScript tips)

## Learn Swift and iOS

- [The Swift Programming Language](https://docs.swift.org/swift-book/): the official book, free
- [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/)
- [Hacking with Swift](https://www.hackingwithswift.com/) and [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui): free, project-based
- [Apple's SwiftUI tutorials](https://developer.apple.com/tutorials/swiftui) and [WWDC videos](https://developer.apple.com/videos/)
- [Stanford CS193p: Developing Apps for iOS](https://cs193p.sites.stanford.edu/): free university course
- [Swift by Sundell](https://www.swiftbysundell.com/): articles and podcast; [Point-Free](https://www.pointfree.co/) and [objc.io](https://www.objc.io/) for advanced topics
- [Swift Testing documentation](https://developer.apple.com/documentation/testing) (what the tests here use)
- [Exercism: Swift track](https://exercism.org/tracks/swift)
- [Swift Forums](https://forums.swift.org/): language discussion

## Learn SQL

- [SQLBolt](https://sqlbolt.com/): short interactive lessons, a good first pass
- [SQLZoo](https://sqlzoo.net/): exercises in the browser
- [Select Star SQL](https://selectstarsql.com/): an interactive book that teaches through real data
- [SQL Murder Mystery](https://mystery.knightlab.com/): solve a crime using only queries (good practice for joins)
- [Mode SQL tutorial](https://mode.com/sql-tutorial): basic to advanced, including window functions
- [SQLite documentation](https://www.sqlite.org/docs.html), especially [the SQL language reference](https://www.sqlite.org/lang.html) and [window functions](https://www.sqlite.org/windowfunctions.html)
- [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) and [Use The Index, Luke](https://use-the-index-luke.com/) (how indexes work)
- [HackerRank SQL](https://www.hackerrank.com/domains/sql) and [LeetCode database problems](https://leetcode.com/problemset/database/): interview-style practice after this repo's track
- [DB Fiddle](https://www.db-fiddle.com/): run SQL online against Postgres, MySQL or SQLite

## Computer science theory (courses and books)

- [CS50x: Introduction to Computer Science](https://cs50.harvard.edu/x/): the best single free course for rebuilding fundamentals, including memory, data structures and algorithms
- [Teach Yourself Computer Science](https://teachyourselfcs.com/): a curated reading and course list
- [MIT 6.006 Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/): free university lectures
- [The Missing Semester of Your CS Education (MIT)](https://missing.csail.mit.edu/): shell, git, debugging, tooling
- [Crafting Interpreters](https://craftinginterpreters.com/): free book; the best explanation of lexers, parsers, ASTs and virtual machines
- [Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/): free book on memory, processes, threads and I/O
- [Nand2Tetris](https://www.nand2tetris.org/): build a computer from logic gates up to a compiler (advanced and optional)
- Books to borrow or buy: *Cracking the Coding Interview* (Gayle Laakmann McDowell), *Grokking Algorithms* (Aditya Bhargava), *Code* (Charles Petzold)

## YouTube channels and playlists

- [Crash Course Computer Science](https://www.youtube.com/playlist?list=PL8dPuuaLjXtNlUrzyH5r6jN9ulIgZBpdo): short, friendly overview of how computers work
- [Computerphile](https://www.youtube.com/@Computerphile): academics explaining computing topics. Search for these titles:
  - "Running a Buffer Overflow Attack" and "Why do buffers overflow"
  - "Just In Time (JIT) Compilers"
  - "Compilers" and "How do interpreters work" style episodes (browse the channel)
- [Ben Eater](https://www.youtube.com/@BenEater): how CPUs and memory work, built on breadboards
- [NeetCode](https://www.youtube.com/@NeetCode): interview problem walkthroughs
- [MIT OpenCourseWare](https://www.youtube.com/@mitocw): the algorithm lectures above
- [freeCodeCamp](https://www.youtube.com/@freecodecamp): long full-course videos on almost everything
- [Fireship](https://www.youtube.com/@Fireship): very short overviews of tech concepts ("in 100 seconds")
- For stack vs heap specifically, search YouTube for "stack vs heap memory" by The Cherno (C++ focused, but the concept is the same).

## Interactive tools (see the idea happen)

- [Python Tutor](https://pythontutor.com/): step through code and watch the stack, heap and objects
- [VisuAlgo](https://visualgo.net/): animated sorting, trees, graphs and data structures
- [Compiler Explorer](https://godbolt.org/): see the machine code a compiler produces
- [TypeScript Playground](https://www.typescriptlang.org/play): see the JavaScript that TypeScript generates
- [Big-O Cheat Sheet](https://www.bigocheatsheet.com/)
- [Regex101](https://regex101.com/): test regular expressions
- [SQLBolt](https://sqlbolt.com/) and [SQLZoo](https://sqlzoo.net/): practise SQL in the browser

## Tech interview preparation

- [Tech Interview Handbook](https://www.techinterviewhandbook.org/): free guide covering coding, system design and behavioural questions
- [interviewing.io](https://interviewing.io/): practice interviews with engineers
- [Glassdoor UK](https://www.glassdoor.co.uk/): reports of what each UK company actually asks
- Write your own STAR stories (situation, task, action, result) for past projects and rehearse them out loud.

## Suggested use

- Learning: CS50P or the Python tutorial for refreshing syntax; CS50x or Crash Course for concepts.
- Practising: this repo first, then LeetCode Easy and NeetCode.
- Passive time (commuting, gym): Computerphile videos and the podcasts above.
